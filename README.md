# Diffusion Latent Representations for Neural Decoding
This repo contains the code used to generate results from the preprint [Diffusion Latent Representations for Neural Decoding](https://www.biorxiv.org/content/10.64898/2026.07.08.737343v1)

This work was performed by [Brandon Wong](https://github.com/wongbr55) supervised by [Brokoslaw Laschowski](https://github.com/DrLaschowski) at The Machine Intelligence Lab.
